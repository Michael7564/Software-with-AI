# Marginal AI
# Description
This is app that allows user to create notes for anything they need. It requires a log of a username and password with a sign up including a email as well but no verification is need for the app.

# Technology use
The main AI I used to help with the coding was Claude Code. for the backend uses Back4app and Netlify is what make it run online instead of locally 

# [marginalai.netlify.app](https://marginalai.netlify.app/login.html))


# Setup Instructions 

1. Create an account
Open the app's link in your browser.
Click Sign up.
Enter a username, your email, and a password (at least 6 characters).
Click Create account. You'll be taken straight into your notes — no email confirmation needed.
2. Log in

If you already have an account:

Open the app's link.
Enter your username and password.
Click Log in.

You'll stay logged in on that browser until you click Log out, even if you close the tab and come back later.

3. Create a note
Click + New note in the left sidebar.
Type a title and write your note in the box below it.
Click Save.

Your note now appears in the list on the left, with the most recently updated notes at the top.

4. Open and edit a note
Click any note in the sidebar to open it.
Make your changes.
Click Save.
5. Delete a note
Open the note you want to remove.
Click Delete.
Confirm when asked. This can't be undone.
6. Log out

Click Log out in the top-right corner. You'll be taken back to the login screen, and no one else using that browser will see your notes.

Notes are private

Only you can see your own notes — no one else who signs up for the app, even with their own account, can view, edit, or delete them.
